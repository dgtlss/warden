# Warden 2.1.0

Warden 2.1 reduces noise in security audits and notifications, and improves checks for applications with custom Laravel paths.

## Notifications only when there are findings

Scheduled audits can now skip empty notifications with `--notify-on-finding`:

```bash
php artisan warden:audit --fail-on=never --notify-on-finding --only=composer
```

The flag enables notifications and sends them only when active findings remain after suppression. It works across Slack, Discord, Teams, and email.

For a shared setting, set `warden.notifications.only_on_findings` to `true`, or use `WARDEN_NOTIFY_ONLY_ON_FINDINGS=true`. If you maintain a published Warden config, add this entry inside its `notifications` array:

```php
'only_on_findings' => env('WARDEN_NOTIFY_ONLY_ON_FINDINGS', false),
```

Existing `--notify` behavior remains the default. Audit reports and exit codes are unchanged, including exit `2` for incomplete scans.

Resolves [#30](https://github.com/dgtlss/warden/issues/30) in [#33](https://github.com/dgtlss/warden/pull/33).

## Fixes

- **Custom storage and environment paths:** Warden now checks Laravel's configured storage directories, bootstrap cache, and environment file, including custom filenames. Permission and Git-tracking findings point to the actual affected location. Resolves [#16](https://github.com/dgtlss/warden/issues/16) and [#17](https://github.com/dgtlss/warden/issues/17) in [#32](https://github.com/dgtlss/warden/pull/32).
- **Fewer false secret alerts:** Supported Laravel validation rules, FormRequest rules, and translation arrays no longer produce misleading suspicious-literal findings. Provider credentials remain detectable, and the scanner now checks every matching assignment on a line. Implemented in [#31](https://github.com/dgtlss/warden/pull/31), following the original proposal in [#29](https://github.com/dgtlss/warden/pull/29).
- **PHP Parser compatibility:** Source analysis now supports the argument placeholders introduced by PHP Parser 5.9, resolving the PHPStan failures with current dependencies.

## Upgrade

This is a backwards-compatible minor release for Warden 2.0. Supported versions remain PHP 8.3–8.5 and Laravel 12–13.

```bash
composer require --dev 'dgtlss/warden:^2.1' --with-all-dependencies
```

The release is checked across all six supported PHP/Laravel combinations and the lowest supported dependencies.
